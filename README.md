# HERACLES Demo Data

This repository contains demo data and analysis results generated by the **HERACLES** pipeline for tsRNA (tRNA-derived small RNA) sequencing analysis.

## Repository Structure

```
HERACLES_demo_data/
├── paper1/                    # Paper 1: Control vs Tumor
│   ├── metadata.tsv           # Sample metadata (GSM IDs, groups)
│   ├── SRA.list               # SRA accession numbers
│   └── paper1_output/         # HERACLES pipeline output
│       ├── counts_matrix.tsv          # tsRNA expression count matrix
│       ├── cluster_results/           # tsRNA clustering results
│       ├── deseq2_results/            # Differential expression analysis
│       ├── extend_primer_results/     # Extended primer analysis
│       ├── prediction_results/        # Target gene prediction
│       ├── qc_results/                # Quality control reports
│       └── tsRNA_results/            # Per-sample tsRNA annotation & counts
│
├── paper2/                    # Paper 2: Control vs Disease
│   ├── metadata.tsv           # Sample metadata (SRR IDs, groups)
│   ├── SRA_list.txt           # SRA accession numbers
│   └── paper2_output/         # HERACLES pipeline output
│       ├── counts_matrix.tsv
│       ├── cluster_results/
│       ├── deseq2_results/
│       ├── extend_primer_results/
│       ├── prediction_results/
│       ├── qc_results/
│       └── tsRNA_results/

├── inhouse_endometriosis/     # Count matrices for the 46-sample in-house cohort
│   ├── fragment_counts.tsv    # Non-clustered matrix (43,554 fragments x 46)
│   ├── cluster_counts.tsv     # Clustered matrix (16,931 clusters x 46)
│   └── metadata.tsv           # Sample groups (Disease / Control)
│
└── figures/                   # Figure generation package (main + supplementary)
    ├── 01_main/               # Figure 1-4: code/, data/, figure/
    ├── 02_supplementary/      # Figure S1-S19: code/, data/, figure/
    ├── 00_shared_data/        # inputs larger than 1 MB, stored once
    └── README.md              # figure -> script -> input manifest
```

## Datasets

### Paper 1 — Control vs Tumor
- **6 samples**: 3 Control (GSM7990419–21), 3 Tumor (GSM7990422–24)
- **SRA accessions**: SRX23007777–SRX23007782

### Paper 2 — Control vs Disease
- **8 samples**: 4 Control (SRR12857075–78), 4 Disease (SRR12857079–82)
- **SRA accessions**: SRR12857075–SRR12857082

## Output Description

| Directory | Contents |
|-----------|----------|
| `counts_matrix.tsv` | Raw tsRNA expression counts across all samples |
| `cluster_results/` | Clustered tsRNA sequences (detailed & simplified summaries) |
| `deseq2_results/` | Differential expression results, volcano plot, heatmap |
| `extend_primer_results/` | Extended primer alignment and significant tsRNAs |
| `prediction_results/` | Target gene enrichment analysis |
| `qc_results/` | Quality control reports |
| `tsRNA_results/` | Per-sample tsRNA annotations and counts |

## Usage

This repository serves as a reference dataset for testing and demonstrating the HERACLES pipeline. Clone the repo and use the data as input for your own analysis.

```bash
git clone https://github.com/Heranova-Lifesciences/HERACLES_demo_data.git
```

## Figure generation package

`figures/` holds the code and input data behind every main and supplementary
figure of the manuscript, so that each panel can be regenerated independently.

Each figure has its own folder with three parts:

- `code/` — the plotting script(s)
- `data/` — the input tables the script reads
- `figure/` — the delivered PDF and PNG

Input files larger than 1 MB live once in `00_shared_data/` rather than being
duplicated. `figures/README.md` lists, for every figure, the script that draws
it and the inputs it consumes; the `NOTES.md` inside each folder gives the same
information locally, plus a short description of what the figure shows.

```
figures/01_main/Figure1..4/
figures/02_supplementary/S01..S19/
figures/00_shared_data/
```

Running a script requires the project layout it expects (paths relative to the
HERACLES project root, such as `cluster_summary_detailed.csv` and
`server_results/results/...`). Copy the file from that figure's `data/` folder,
or from `00_shared_data/`, into the expected location, then run the script with
Python 3 and the packages in `figures/requirements.txt`.

Raw FASTQ files for the in-house cohort are not redistributed here; they are
available through controlled access under HRA019031.

## In-house endometriosis cohort

`inhouse_endometriosis/` provides the processed count matrices for the 46
peripheral-blood libraries analysed in the manuscript (20 cases, 26 controls).

| File | Contents |
|---|---|
| `fragment_counts.tsv` | Non-clustered matrix: 43,554 tsRNA fragments x 46 libraries |
| `cluster_counts.tsv` | Clustered matrix: 16,931 clusters x 46 libraries |
| `metadata.tsv` | Sample group for each library |

Both matrices are tab-separated integer counts and carry the same total of
40,135,349 reads; the clustered matrix sums the counts of all fragments
assigned to each cluster and names the row after its representative. See
`inhouse_endometriosis/README.md` for the identifier format and the exact
pipeline settings used.

Raw FASTQ files are not included. They remain under controlled access at
HRA019031.
